统计与隐私

网站仅对公开的每期 Paper Digest 和每篇 Tech Notes 记录页面访问，不将打开页面等同于读完文章。

启用统计后，浏览器向站主的 HTTPS 服务发送文章路径和一次性的随机请求编号。服务用上海日期、网络地址与浏览器信息生成带密钥的摘要，估算当日独立访客；不将原始 IP、浏览器信息、搜索词、收藏或摘录写入统计文件。每篇文章的累计浏览次数公开显示；独立访客数和详细后台仅供站主查看。关闭统计后，页面仍可只读查询公开浏览次数，这类查询不计数。

重复刷新会增加访问次数，同一天同一网络地址与浏览器通常只计一位访客。共享网络可能合并不同读者，更换网络或设备可能重复计数。统计不用于识别个人，不跨日期关联访客；不同日期的独立访客不能直接相加当作总人数。

浏览器的 Do Not Track 或 Global Privacy Control 信号会阻止发送。预览站、自动化测试、搜索页和私人收藏页不计数。你也可以关闭此浏览器的统计；关闭标记仅保存在本地，清理浏览器数据后需重新设置。

Analytics & privacy

Analytics covers only published Paper Digest issues and Tech Notes. Opening a page is not evidence that someone finished reading it.

When enabled, your browser sends the article path and a one-time random request ID to the site owner's HTTPS service. The service combines the Shanghai calendar date, network address and browser information into a keyed digest to estimate daily unique visitors. Raw IP addresses, browser information, search terms, bookmarks and excerpts are not written to analytics files. Each article displays its cumulative pageviews publicly; unique-visitor counts and detailed reports remain private. Opting out stops counting but still allows a read-only request for the public counter, which does not record a visit.

Reloads increase pageviews. The same network address and browser usually count as one visitor per day. Shared networks can merge readers; changing networks or devices can count someone again. No identity is inferred or linked across dates. Daily visitor counts must not be added and presented as unique people across days.

Do Not Track and Global Privacy Control signals suppress collection. Previews, automated tests, search pages and private bookmarks are excluded. You can also disable analytics in this browser. This preference is stored locally and must be set again if browser data is cleared.
