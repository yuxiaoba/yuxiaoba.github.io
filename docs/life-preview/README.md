# Life 照片布局示例

2026-10-19：用户希望展示实物照片与探店照片，先比较不同图片比例的布局。本轮仅提供独立设计示例，未向 Life 集合加入文章。

示例使用 12 张明确标注的 SVG 比例占位图，包含横图、竖图和方图，没有真实店名、评价或用户经历。三组相册可以切换，并可比较原比例排列与 4:3 裁切网格；点击图片打开完整图。页面设置 noindex，不进入 Life 列表或全文搜索。

## 推荐布局

- 每次探店或一组实物照片作为一篇记录，列表选一张 4:3 封面。只在显示时裁切，可按真实照片调整焦点，原图保持完整。
- 记录内使用原比例照片墙，桌面三列、平板和手机两列。列宽一致、图片高度随比例变化，不拉伸图片。
- 如果文字和照片需要明确的阅读顺序，改为单列图文；当前 CSS 多栏是先从上到下，再到下一列，不适合逐行叙事。
- 统一裁切网格更整齐，但会裁掉竖图和方图的部分画面，所以仅作为对比选项。
- 手机上的记录封面支持横向滑动。照片原图链接可直接打开完整图。

真实内容接入时继续沿用 `_kitchen/{zh,en}/` Markdown 与现有发布规则，图片可保存在每篇独立的 assets 目录；正文和图片说明由用户真实内容维护。本轮未实现新的内容字段、图片压缩流水线或正式相册模板。

## 本机预览机制

`gallery.css` 和 `gallery.js` 是独立示例样式与交互。`.preview/life-layout-demo/build.py` 从当前源码创建临时快照，生成双语页面和占位图，调用现有构建流水线，成功后原子切换本机预览。未修改正式页面模板或原始笔记。

示例仅存在于此次预览 release，普通源码重建会恢复常规网站；如需重新查看，可在本机执行上述 build.py。它不执行 Git 推送或远端部署。不要把示例生成目录作为正式内容提交。
