# 首页最近更新

首页顺序为个人介绍卡片 → About Me → 学术 News → 最近更新 / Recent Updates。最近更新展示最新一期 Paper Digest 和最近两篇 Tech Notes。Life 从首页正文移除，只保留顶部导航入口与独立栏目页；旧的底部论文入口已移到这里，避免同一篇日报在首页重复出现。

入口由 `_includes/homepage-updates.html` 和 `recent-note.html` 渲染，无须维护首页文章列表。

- 只读取当前语言中 `published: true` 的 `_digest`、`_tech` 内容。
- 首先按 Markdown 的阅读日期 `date` 倒序，同一日期内按 `updated_at`（否则 `published_at`，再否则 `date`）倒序；同一批次完全同一时刻时以路径稳定排序。首页和阅读归档共用 `ordered-notes.html`，不使用文件修改时间或每次构建时间。
- 日任务在候选准备发布时为完整双语批次记录同一个带时区的 `published_at` / `updated_at`，实际入站后保留；旧文更新不改阅读日期，原发布时间已知时不覆盖。缺少可靠历史记录的旧稿维持日期回退，不编造精确时刻。
- 2026-10-21 从已有成功发布报告和完成记录回填了可核验的历史时间；只知道追加时间的原稿仅填写 updated_at。以后手动修改已发表内容时可为中英文同时填写实际 updated_at，例如 `2026-10-21T16:30:00+08:00`。旧日期文章不会仅因更新就压过新日期日报。
- 展示日期、标题、已有 `summary`。日报有 `daily_digest` 和 `paper_count` 时额外显示论文数量。
- 为避免日期重复，首页只移除与 date 精确匹配的标准标题前缀（中文 `YYYY年M月D日｜`、英文 `YYYY-MM-DD | `）。原 Markdown 和文章页标题不改；不符合格式的标题完整显示。
- 不展示运行状态、失败日志、RSS 或未生成的每周总结。只有一种语言时，另一个语言首页继续显示自身已有文章或真实空状态。
- 桌面两栏，700px 以下依次显示日报和技术笔记；原图、论文正文与资料内容不受影响。

每日任务通过校验后写入完整双语 Markdown，后续完整构建会自动更新首页。不能把 Grok 原始收件文件直接当作最近更新。

验证：`python3 scripts/verify_site.py` 覆盖日期排序、数量上限、草稿与缺译隔离、日期标题展示及临时新内容自动进入首页。浏览器截图与响应式检查在 `.preview/home-updates/`。

## Paper Digest / Tech Notes 月度归档

两栏目共用 `digest-entries.html`，顶部保留最新文章，归档按文章阅读日期自动分月倒序。最新有内容的月份默认展开，历史月份默认折叠；月份行显示本语言公开内容的数量（Paper按期、Tech按篇）。原生 details/summary 支持鼠标、触屏与键盘，无需额外JavaScript。

折叠只影响归档显示，文章URL、全文搜索、标签与年月筛选保持。草稿和缺失译文不计入月份与数量，无须在Markdown增加字段。跨月份／跨年份归档、默认展开、数量与折叠月份仍入搜索索引由临时fixture验证。

归档条目与顶部最新卡片显示文章已有的主题标签，只使用 `_data/note_tags.yml` 现有8类词汇并按当前语言呈现；自动换行，不增添未确认标签或修改文章分类。

标签采用8类固定浅色配色，以data-topic稳定ID绑定，中文和英文同主题同色。保留文字名称，颜色不作为唯一识别信息；全部正文／底色对比度至少4.5:1。
