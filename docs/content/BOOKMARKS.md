# 私人阅读收藏

顶部书签图标进入 `/zh/bookmarks/` 或 `/bookmarks/`。Paper Digest 和 Tech Notes
支持收藏整篇笔记；日报内每篇论文还有独立收藏按钮。选中正文文字后可保存摘录，
保留摘录、文章标题、章节、原文定位链接和保存日期。收藏页可回看、取消、导入或导出JSON备份。

收藏使用当前站点、当前浏览器的 localStorage，不上传到服务器、GitHub、搜索索引或
每日任务。中英文界面共用收藏，但保留收藏内容的原语言。不同设备、浏览器、预览站与
正式域名不会自动同步；需要手动导出/导入备份。清除浏览器数据、退出无痕窗口或浏览器
清理站点数据可能移除收藏，备份文件应自行保存。

导入合并去重，不清空现有收藏。只接受本站论文/技术阅读路径，文本以textContent渲染；
不执行导入HTML。最多1000条，单条摘录6000字符，总存储及导入文件最多2MiB。存储不可用、
空间不足、损坏或非法备份时显示错误，不伪称已保存。摘录保留所选原文，跳转定位到
相邻章节；文章未来修订或删除时，保存的摘录仍保留，但链接可能变化。

无需数据库、账号、API或额外服务。关闭JavaScript后阅读正常，收藏需要JavaScript。

验证：`python3 scripts/check_bookmarks_browser.py --base http://127.0.0.1:4001`。
测试使用隔离浏览器上下文，收藏不会上传，不会操作日任务。指定正式域名时同样只写
测试浏览器自己的存储；验证结果与截图保存在 `.preview/bookmarks/`。
